# Multi-Agent Research Assistant

A LangGraph-based research assistant that plans research, gathers information from multiple sources, verifies claims, and produces a cited answer.

## Status

Early development.

Current work focuses on the LangGraph state, question validation, and graph structure.

## Planned flow

`Question → Plan → Research → Verify → Critique → Synthesize`

## Stack

* Python
* FastAPI
* LangGraph
